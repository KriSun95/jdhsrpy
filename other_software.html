Additional NuSTAR Software

There is a lot of software out there to work with NuSTAR data. A non-exhaustive list exists here:

  • HEASoft

    • This is the official software to work with the NuSTAR, and other instrument’s, pipeline.

  • heasoft-test-base

    • This repository contains some Python and Bash scripting to test an existing HEASoft install by processing downloaded NuSTAR files and fitting them with XSPEC. This can also be useful just to see the complete workflow.

  • nustar_pysolar

    • A repository with helpful NuSTAR tools in Python, mainly for solar analysis.
